# 꼼꼼모아
꼼꼼하게 비교하고, 알뜰하게 모아요. 로그인 없는 모바일 우선 가격 비교 웹앱입니다.

## 실행
저장소 폴더에서 `npm start` 또는 `python3 -m http.server 3000`을 실행한 뒤 브라우저로 `http://localhost:3000`을 여세요. ES 모듈을 사용하므로 index.html을 더블클릭하는 대신 HTTP 서버로 실행하세요. 별도 패키지 설치는 필요하지 않습니다. 테스트는 Node.js 20 이상에서 `npm test`로 실행합니다.

## 파일 안내와 수정 방법
- `index.html`: 공통 헤더, 하단 메뉴, 기본 문서. 서비스명이나 검색 설명을 수정합니다.
- `css/style.css`: 소프트 네이비 색상, 반응형 화면, 글자 크기. 맨 위 색상 변수를 바꾸면 전체 테마가 바뀝니다.
- `js/app.js`: 홈, 입력, 결과, 기록, 설정 화면과 사용자 이벤트. 화면 문구와 기능을 수정합니다.
- `js/products.js`: 대표 상품과 컬러 이모지 아이콘. 목록에 상품명·추천 단위·그림 종류를 추가합니다.
- `js/calculator.js`: 순수 계산 함수. 단위 환산·할인 규칙은 이 파일에서 수정하고 테스트를 실행하세요.
- `js/storage.js`: 브라우저 localStorage 기록 읽기와 저장.
- `tests/calculator.test.js`: 환산, 할인, 묶음, 쿠폰, 무료 상품, 잘못된 입력 테스트.
- `assets/icons/`: 이후 별도 이미지 파일을 추가할 수 있는 폴더. 현재 아이콘은 products.js의 컬러 이모지입니다. 기기에 따라 모양이 조금 달라집니다.

## 계산 기준
입력 가격은 한 묶음 판매가격입니다. 총 용량은 한 개 용량 × 묶음 수량 × 행사 수령 묶음 수입니다. 1+1은 1묶음 가격으로 2묶음을 받고, 2+1은 2묶음 가격으로 3묶음을 받습니다. 할인 후 전체 금액에서 쿠폰을 한 번 빼고 배송비를 한 번 더합니다. 쿠폰이 상품 금액을 넘으면 오류를 표시합니다. 결제 금액 0원은 100% 할인에서 허용합니다. 비교에는 반올림 전 값을 사용하고 표시만 소수 둘째 자리까지 반올림합니다.

기록과 글자 확대 설정은 현재 브라우저에만 저장됩니다. Pretendard는 CDN에서 불러오며 네트워크가 없으면 시스템 글꼴로 표시됩니다. 광고·회원가입·OCR·AI 기능은 없습니다.

## 배포와 다음 단계
Vercel에 이 저장소를 연결하고 Framework Preset은 Other, Build Command는 비움, Output Directory는 `.`로 설정하는 정적 배포가 가능합니다. 현재 자동 업로드나 배포는 수행하지 않았습니다.

다음 단계는 실제 20대·중장년 사용자 사용성 검증, 세 상품 이상 비교, 기록 내보내기, 가격 추이, PWA 오프라인 지원입니다. 기기 간 동기화는 계정 및 서버 설계를 별도로 진행해야 합니다.

## 내 기록과 가격 변화
`js/history.js`는 저장된 입력을 다시 계산하고 날짜순으로 정리합니다. 내 기록에서 저장 건수·상품 종류·비교 결론·A/B 단위가격을 확인하고 이전 비교를 불러와 가격만 수정할 수 있습니다. 가격 변화는 같은 상품명과 단위 종류의 바로 이전 기록을 찾아 A→A, B→B로 비교합니다. 할인·묶음·쿠폰·배송비를 포함한 결제금액을 기준량으로 환산하며, 이전 가격이 0원이면 증감액만 표시합니다. 브랜드·구성이 같은지는 사용자가 확인해야 합니다. 예시 카드는 실제 기록이나 통계에 포함되지 않습니다. 관련 검증은 `tests/history.test.js`에 있습니다.
